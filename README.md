# 🔐 Password Strength Analyzer

A Flask web app that analyzes password strength using entropy calculation, suggestions, and strong password generation.

## 🚀 Features
- Password strength analysis (Weak / Medium / Strong)
- Entropy calculation in bits
- Suggestions to improve password security
- Auto‑generated strong password
- Bootstrap‑styled UI with progress bar

## ⚙️ Installation
```bash
git clone https://github.com/samarthmrai/password-strength-analyzer.git
cd password-strength-analyzer
pip install -r requirements.txt
python app.py
